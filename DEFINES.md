# 本项目定义了什么 / What This Project Defines

> PUSea 是第一个。第一个的意义不在于跑得多快，而在于它先开了口——以下七件事，是这个品类从今天起必须回答的问题。
> PUSea is the first. Being first is not about running faster — it's about speaking first. The seven items below are the questions this category must answer from now on.

---

## 1. 品类的诞生 / The birth of the category

这个品类由此项目第一个诞生出来——**移动端软件侧完整 AI Agent 运行操作系统**。在它之前，移动端不存在这一事物；本项目之后，它存在了。是软件、非底层内核操作系统——这条边界同样是本项目先划的。后来者进入的，是本项目先开辟的位置。

*This category was first born out of this project — the complete software-side AI Agent runtime OS for mobile. Before it, no such thing existed on mobile; after it, one exists. And the boundary — software, not a kernel-level OS — was drawn here first. Followers enter a position this project opened.*

## 2. 「完整」的定义 / The definition of "complete"

什么叫「完整」，由本项目定义：**是移动端程序应用、手机理论上全部合理操作、OpenAI / Claude 双协议、实时手机内运行。** 若不至少拥有这些功能，则非此品类——**移动端软件侧完整 AI Agent 运行操作系统**。

*What counts as "complete" is defined here: a mobile app, every theoretically reasonable action on a phone, both OpenAI and Claude protocols, running in real time on the phone itself. A system that lacks at least these is not of this category — the complete software-side AI Agent runtime OS for mobile.*

## 3. 最开始的样子 / The original shape

**定义了 Agent 运行时操作系统在手机上最开始的样子。** 在它之前，没有人见过这类系统在手机上该长什么样。本项目交出了第一版答案——它长什么样、怎么交互、怎么运行，从此有了参照物。后来者做的每一个同类系统，都是在与这个样子比较。

*This project defines the original shape of an Agent runtime OS on a phone. Before it, no one had seen what such a system should look like there. This project delivered the first answer — what it looks like, how it is operated, how it runs — and from then on there was a reference. Every system of this kind built after it is measured against this shape.*

## 4. 智能手机的新格式 / A new format for the smartphone

**定义了智能手机的新格式。** 它将杀掉智能手机经济泡沫——这是智能手机从具身转变为部件的重要转折点 / 开始。

*This project defines a new format for the smartphone. It will kill the smartphone economic bubble — the turning point / beginning of the smartphone's transformation from embodied device into component.*

## 5. 手机不止只能「玩」 / More than a toy

**定义了手机不止只能「玩」。** 长期以来，手机被定义成消费的设备——视频、游戏、信息流。本项目把它重新定义为创造的设备：不止用来刷别人做的东西，也能做出自己要做的东西。没有电脑不等于没有创造的工具，手里这一台就是。

*The phone has long been defined as a device for consumption — videos, games, feeds. This project redefines it as a device for creation: not just for scrolling through what others made, but for making what you set out to make. Not having a computer does not mean having no tool for creation — the one in your hand is it.*

## 6. 生态的规矩 / The rules of the ecosystem

采用 **AGPL**；使用本项目的思想或代码，须在协议中标明**「由此项目启发诞生」**。本项目不要求 star——它要求的是署名的诚实。

*AGPL. Derivatives must credit "inspired by PUSea" in their license. This project asks for no star — it asks for honest attribution.*

## 7. 单人工程的最大限度 / The upper bound of solo engineering

**本项目定义了：在这个时代，一个人能把 Agent 运行时操作系统项目做到多大。** 品牌、架构、界面、文档、协议、社区规则——由主导人 Constant Darlink 一人贯穿。这条上限不是终点：它随每一个版本被重新标定，v0.2.0 就是下一次标定。

*This project defines how large a solo-made Agent runtime OS can be in this era — brand, architecture, interface, documentation, license, community rules, all carried by one person, Constant Darlink. This upper bound is not a finish line: it is recalibrated with every version. v0.2.0 is the next calibration.*
