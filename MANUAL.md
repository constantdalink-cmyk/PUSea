## 一、你只用会四个动作 / Four moves are all it takes

想用这个，你只用会：**说、点、划、按**。

UI 是用来探索的。

To use this, all you need is: **speak, tap, swipe, press**.

The UI is meant to be explored.

至于项目代码原理说明书嘛……我不知道为什么要说。开源的目的本身就不是教你用、教你理解——我只管开源，不管你的衣食起居。我不赚钱。

As for a manual on the code and how it works… I don't know why I should write one. The point of open source was never to teach you how to use it, or to make you understand it. I only open-source it — I'm not in charge of your meals and your daily life. I make no money from this.
